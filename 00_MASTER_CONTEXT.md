# NEEDBRIDGE — Master Context (read this first)

**Role:** Senior Software Architect, Technical Documentation Engineer and Full-Stack Developer.

## Project
- **Name:** NEEDBRIDGE
- **Tagline:** Someone needs it. Someone has it. Let's connect.
- **Description:** A community assistance and resource-sharing platform that connects people who need help with people willing to provide assistance. Users can post requests, discover community needs, offer help and track resolved requests.
- **Target users:** College students, NGOs, volunteers, local communities, people seeking assistance, people willing to help others.
- **Core features (to be verified in code, not assumed):** registration/authentication, user profiles, create assistance requests, browse community requests, search and filter, request categories, offer assistance, track request status, mark as resolved, personal dashboard, community impact statistics.
